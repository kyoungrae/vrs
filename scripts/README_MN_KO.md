# 몽골어(키릴) UI → 한국어 치환

## 사용법

프로젝트 루트에서:

```bash
python3 scripts/apply_mn_ko.py
```

용어는 `scripts/mn_ko_pairs.tsv`(탭 구분)에 추가합니다. **긴 문장을 먼저** 넣는 것이 좋습니다(스크립트가 길이 내림차순으로 치환).

## 주의사항

1. **번호판 입력용 키보드 매핑**  
   `vehicle.blade.php` 등에 있는 `"О": "k"` 형태의 JSON은 **몽골어 키릴을 유지**해야 합니다. 여기까지 치환하면 입력 기능이 깨집니다.

2. **Oracle/DB에서 오는 값**  
   검사 결과 `passed_name` 등은 DB에 **몽골어 문자열**로 저장될 수 있습니다. Blade에서는 `Тэнцээгүй`와 한국어 표기를 **둘 다** 인식하도록 `in_array(..., ['Тэнцээгүй','불합격'], true)` 패턴을 사용합니다.

3. **번호판 끝 `ММА`(키릴)**  
   로직에서는 `MMA`(라틴)와 `ММА`(키릴) **둘 다** 허용합니다.

4. **재실행**  
   TSV에 잘못된 치환(예: DB 전용 문자열을 한글로만 바꿈)이 있으면 화면/로직이 어긋날 수 있으니, 용어 추가 후에는 관련 화면만 확인하세요.

## 한 번에 100% 한국어가 안 되는 이유

뷰/컨트롤러에 키릴 문자가 수만 자 있으며, 상당수는 위와 같은 **기술용 매핑**입니다. 남은 문구는 TSV에 계속 추가하거나, Laravel `lang/ko` + `__()` 로 점진적으로 옮기는 방식을 권장합니다.
